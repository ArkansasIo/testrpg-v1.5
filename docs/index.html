CORE FEATURES

Small client. Deep systems.

Automatic Combat

Combat resolution, damage, targeting, boss attacks, and wave progression are modeled as reusable systems.

Loot & Equipment

Rarity tiers, equipment slots, class restrictions, derived stats, inventory stacks, and loot generation.

Waves & Bosses

Scaled enemy waves, role-based enemies, scheduled boss encounters, and enrage mechanics.

Party Progression

Recruit heroes, gain XP, level up, unlock skills, and maintain a persistent party state.

ARCHITECTURE

Data-driven RPG modules

GameState
├── Party[]
│   └── Hero
│       ├── Stats{}
│       ├── Abilities[]
│       └── Equipment{}
├── Inventory[]
│   └── Item
├── Stage → Wave[] → Enemy[]
├── Dungeon → Floor[] → Encounter[]
├── Quest → Objective[]
└── SkillTree → Node[]

The repository separates runtime behavior from content definitions. JavaScript modules implement systems while JSON definitions provide classes, enemies, abilities, biomes, and schemas. Type contracts and deterministic RNG make the systems easier to test and extend.
